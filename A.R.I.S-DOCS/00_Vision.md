# Visione

ARIS (Artificial Reasoning and Intelligent System) è un assistente AI personale multimodale ispirato a J.A.R.V.I.S.

L'obiettivo del progetto è creare un sistema capace di comprendere, ragionare e agire all'interno dell'ambiente digitale dell'utente attraverso linguaggio naturale, visione artificiale e automazione.

ARIS deve fungere da interfaccia unificata tra l'utente, il computer, il web e i servizi esterni.

Il sistema dovrà essere:

- Conversazionale
- Proattivo
- Modulare
- Estensibile
- Sicuro
- Controllabile dall'utente

ARIS non è semplicemente una chat AI.

ARIS è un sistema operativo cognitivo costruito attorno all'utente.
