# Principi di Design

## Voice First

Ogni funzionalità deve essere utilizzabile tramite voce.

## Human Override

L'utente può interrompere qualsiasi azione.

## Explainability

ARIS deve poter spiegare cosa sta facendo.

## Permission Based Actions

Le azioni sensibili richiedono autorizzazione.

## Agent Specialization

Ogni agente deve avere una responsabilità chiara.

## UI Minimalism

La UI deve mostrare solo ciò che è necessario.
